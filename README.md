# HydroTM

Hartă interactivă cu hidranții și sursele de apă din Timișoara și împrejurimi, pentru pompierii ISU Timiș.
Instrument informativ: verificați starea și poziția hidrantului la fața locului.

- Aplicația: `index.html` · modulul de administrare: `admin.js` · datele: `hidranti.json`
- Sursele: `src/` · build: `npm install && node build.js --final`, apoi se copiază `dist/*` în rădăcină.
